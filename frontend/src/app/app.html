⚡ EV Charge Finder Architecture

Backend Status: {{ isBackendOnline ? '🟢 Connected (Node.js Express on port 3000)' : '⚪ Standalone Browser Storage' }}

Separation of Concerns:

  • Frontend Persistence: All station additions, updates, deletions, and user preferences are saved immediately to browser Local Storage (ev_stations, ev_favorites, ev_preferences).
  • Backend Demonstration API: The lightweight Node.js Express server provides endpoints (/api/health, /api/stations, /api/stations/:id, /api/info) without requiring any external database.
  • Offline Resilient: Frontend automatically falls back to bundled demonstration records if the backend is stopped.

Backend API Endpoints:

GET http://localhost:3000/api/health GET http://localhost:3000/api/stations GET http://localhost:3000/api/stations/:id GET http://localhost:3000/api/info
